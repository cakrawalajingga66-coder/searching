Algoritma Pencarian (Searching)

Pelajari cara komputer menemukan data secara cerdas dan sistematis melalui konsep berpikir komputasional serta simulasi interaktif Pencarian Berurutan (Linear Search).

💡 Konsep Dasar Algoritma Pencarian (Searching)

Dalam kehidupan sehari-hari, kita sering melakukan proses pencarian. Contohnya ketika kamu mencari nomor kontak teman di ponsel, mencari buku dengan judul tertentu di rak perpustakaan, atau mencari kaus kaki favorit di lemari pakaian.

Definisi Searching dalam Informatika:
Searching adalah proses sistematis untuk menemukan posisi atau keberadaan suatu data tertentu (disebut Key atau Target) di dalam kumpulan sekumpulan data (disebut Array atau List).

Komputer tidak bisa melihat seluruh isi memori sekaligus seperti mata manusia. Komputer harus memeriksa data satu per satu atau menggunakan aturan matematis tertentu. Hasil pencarian biasanya berupa:

  • Ditemukan (Found): Mengembalikan posisi atau nomor indeks elemen data tersebut.
  • Tidak Ditemukan (Not Found): Memberikan sinyal bahwa data yang dicari tidak ada dalam koleksi.

🔎 Jenis-Jenis Algoritma Pencarian

Metode 1 Pencarian Berurutan (Linear Search)

Metode pencarian paling sederhana. Komputer memeriksa elemen data satu per satu dari awal (indeks 0) hingga akhir secara berurutan sampai nilai yang dicari cocok atau seluruh data selesai diperiksa.

  • Syarat Data: Bebas (bisa acak / tidak terurut).
  • Kasus Terbaik (Best Case): Target ada di posisi pertama (1 kali cek).
  • Kasus Terburuk (Worst Case): Target di posisi terakhir atau tidak ada (memeriksa semua N data).

Metode 2 Pencarian pada Data Terurut

Jika data sudah terurut (misal dari kecil ke besar), kita bisa menerapkan algoritma yang jauh lebih efisien seperti Binary Search (Pencarian Bagi Dua).

  • Syarat Data: Wajib terurut (Ascending / Descending).
  • Prinsip: Periksa elemen tengah. Jika target lebih kecil, cari di paruh kiri; jika lebih besar, cari di paruh kanan.
  • Efisiensi: Mengeliminasi separuh data di setiap langkah! Sangat cepat untuk jutaan data.

Perbandingan Ringkas (Linear Search vs. Binary Search)

Aspek Linear Search (Berurutan) Binary Search (Bagi Dua)
Kondisi Awal Data Data boleh acak (tidak perlu terurut) Data wajib sudah diurutkan terlebih dahulu
Kompleksitas Waktu O(n) - Bertambah sebanding dengan jumlah data O(log n) - Sangat hemat langkah
Kemudahan Pembuatan Sangat mudah dipahami dan diimplementasikan Sedikit lebih rumit karena membutuhkan pembagian interval
Kapan Digunakan? Data sedikit atau data dinamis yang sering berubah acak Data berukuran besar yang sudah tersusun rapi (misal kamus)

Pseudocode (Alur Logika) Linear Search

ALGORITMA LinearSearch(Array A, Nilai Target)
1. Untuk setiap indeks i dari 0 sampai panjang(A) - 1 lakukan:
2.    Jika A[i] sama dengan Target maka:
3.       Tampilkan "Ditemukan pada indeks " + i
4.       Hentikan proses (Return i)
5. Jika perulangan selesai dan tidak ada yang cocok:
6.    Tampilkan "Data tidak ditemukan" (Return -1)
SELESAI
